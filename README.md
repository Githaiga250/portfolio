# Portfolio Website

A simple static portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main portfolio page
- `styles.css` — responsive styling and dark mode support
- `script.js` — theme toggle and demo form handling

## Run locally

1. Open `index.html` in your browser.
2. Or use a local server such as VS Code Live Server.

## Customize

- Replace the name, bio, and project descriptions in `index.html`.
- Update the color palette in `styles.css`.
- Add your real contact form backend if needed.
